# PSA2-COM102-Zheng-Haowen

COM102 Object Oriented Programming - Practical Skills Assessment 2.

Scenario B: Library Management System. A console application written in Java
that manages books, magazines, DVDs and e-books, plus the members who borrow
them.

## Status

Project set up. Source code is being written.

## How to run

Open the folder as a project in IntelliJ IDEA (JDK 21) and run `library.Main`.

## Project layout

```
src/library   application source code
test/library  JUnit 5 tests
lib           JUnit 5 console runner (used for tests outside the IDE)
data          text file used by the program to save records between runs
docs          design and testing documents
```
